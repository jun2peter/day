# Day — 구글 시트로 관리하는 달력 · 체크리스트

**사이트:** https://jun2peter.github.io/day/ (컴퓨터·폰 모두)

- **달력 탭** — 한 달 달력. 날짜를 누르면 그날 일정과 할 일이 옆(폰은 아래)에 떠요.
- **오늘 탭** — 그날의 체크리스트. 누르면 완료 체크, 진행률 표시. 이번 주 안에 할 일, 밀린 할 일도 같이.
- **마감 알림** — 시트 `알림` 칸에 `3일 전`처럼 적으면 그때부터 사이트 위쪽과 오늘 탭에 `D-3` 으로 떠요.
- **반복** — 매일 · 평일 · 매주 · 요일 지정 · 격주 · 매월 · 매년 · 매주 아무 때나 한 번.
- **시트가 원본** — 시트를 고치면 사이트에 알아서 반영(화면을 다시 열 때 + 열어두면 1분마다). 사이트에서 체크하거나 `+`로 추가한 것도 시트에 저장돼요.
- **사이트에서 고치기** — 항목 옆 `⋯` 를 누르면
  - **○일만 빼기**: 반복 항목에서 그날(주간 할 일은 그 주)만 없애요. 시트에서는 '그 전날까지' 줄과 '다음부터' 줄 두 줄로 나뉘어요.
  - **수정하기**: 제목·날짜·시간·반복·알림·메모를 고쳐요.
  - **지우기**(두 번 누름): 시트에서 그 줄을 지워요. 반복 항목은 모든 날짜에서 사라져요.
  - 잘못 눌렀으면 아래에 뜨는 `되돌리기`. 고친 줄은 시트 맨 아래로 옮겨져요.
- 인터넷이 끊겨도 마지막 내용을 보여주고, 그동안 한 체크는 다시 연결되면 시트에 올라가요.

---

## 처음 한 번만 설정하기 (5분)

### 1. 시트에 연결 코드 넣기
1. 플래너로 쓸 구글 시트를 열어요 (새 시트여도 돼요).
2. 메뉴 **확장 프로그램 → Apps Script**.
3. 원래 있던 코드를 다 지우고 [`apps-script/Code.gs`](apps-script/Code.gs) 내용을 통째로 붙여넣고 💾 저장.

### 2. 웹 앱으로 배포하기
1. 오른쪽 위 **배포 → 새 배포**.
2. 톱니바퀴(유형 선택) → **웹 앱**.
3. **실행 사용자: 나**, **액세스 권한이 있는 사용자: 모든 사용자** → **배포**.
4. 권한 요청이 뜨면 내 계정 선택 → "Google에서 확인하지 않은 앱" 화면이 나오면 **고급 → (프로젝트 이름)(으)로 이동** → **허용**.
   (내가 만든 코드라 생기는 정상적인 경고예요.)
5. 나온 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사.

### 3. 사이트에 연결하기
1. 사이트 오른쪽 위 ⚙ → URL 붙여넣기 → **연결하기**.
2. 시트에 `일정` · `체크리스트` · `완료기록` 탭이 없으면 이때 자동으로 만들어져요.

### 4. 폰에서도 쓰기
1. 컴퓨터 사이트 ⚙ → **연결 링크 복사** → 카톡 '나와의 채팅' 등으로 폰에 보내고 열기. 끝!
2. 폰 브라우저 메뉴에서 **홈 화면에 추가**하면 앱처럼 쓸 수 있어요.

> 🔒 웹 앱 URL과 연결 링크는 **열쇠**예요. 가진 사람은 내 일정을 보고 체크할 수 있으니 남에게 보내지 마세요.
> 이 저장소(깃허브)에는 URL이 들어있지 않아서, 사이트 주소만 알아서는 아무것도 볼 수 없어요.

## 시트 쓰는 법

첫 줄(제목줄)은 그대로 두고, 둘째 줄부터 한 줄에 하나씩 적어요. 칸 순서를 바꾸거나 칸을 더 만들어도 괜찮아요(제목줄 이름으로 찾아요).

### `일정` 탭

| 날짜 | 시작 | 끝 | 제목 | 반복 | 반복끝 | 알림 | 메모 |
|---|---|---|---|---|---|---|---|
| 2026-10-21 | 18:00 | | 기획서 마감 | | | 3일 전 | PDF로 제출 |
| | 07:00 | 07:40 | 아침 운동 | 매일 | | | |
| 2026-10-19 | 10:00 | 11:00 | 팀 회의 | 매주 | 2026-12-31 | | |
| | | | 카드값 확인 | 매월 25일 | | 2일 전 | |
| 2026-11-03 | | | 엄마 생신 | 매년 | | 1주 전 | |

- **시작/끝**을 비우면 '종일' 일정.
- **날짜**는 `2026-10-21`, `2026. 10. 21`, `10/21` 다 돼요. 반복 일정이면 '이날부터 시작'이라는 뜻(매일·평일·요일 반복은 비워도 됨).

### `체크리스트` 탭

| 날짜 | 할 일 | 반복 | 반복끝 | 알림 | 메모 |
|---|---|---|---|---|---|
| | 물 2L 마시기 | 매일 | | | |
| | 영어 단어 30개 | 평일 | | | |
| | 분리수거 | 화,금 | | | |
| | 방 청소 | 주간 | | | |
| 2026-10-20 | 과제 제출 | | | 2일 전 | |
| | 책 반납하기 | | | | |

- **날짜만** 적으면 그날 하루 할 일. 그날 못 하면 오늘 탭 '밀린 할 일'에 남아요(60일까지).
- **날짜도 반복도 비우면** '언제든' 할 일 — 체크할 때까지 매일 보여요.
- `주간` = 그 주 아무 날이나 한 번 하면 되는 일(이번 주 안에 칸에 떠요).

### 반복 칸에 쓸 수 있는 말

| 적는 말 | 뜻 |
|---|---|
| (빈칸) | 반복 안 함 |
| `매일` · `평일` · `주말` | 말 그대로 |
| `매주` | 날짜 칸의 요일마다 |
| `월,수,금` · `화목` · `일요일` | 그 요일마다 |
| `격주` · `격주 토` | 2주마다 |
| `매월` · `매월 15일` · `매월 말일` | 매달 |
| `매년` | 날짜 칸의 월·일마다 (생일 등) |
| `3일마다` | 날짜 칸부터 3일 간격 |
| `주간` | (체크리스트만) 매주 아무 때나 한 번 |

**반복끝**에 날짜를 적으면 그날까지만 반복해요.

### 알림 칸 (마감 알림)
`당일` · `1일 전` · `3일 전` · `D-5` · `1주 전` · `2주 전` · `한 달 전`
→ 그만큼 전부터 사이트 위쪽 알림줄, 오늘 탭 '다가오는 마감', 탭의 빨간 숫자에 `D-3`처럼 떠요. 할 일은 체크하면 사라져요.

### `완료기록` 탭
사이트에서 체크하면 여기에 한 줄씩 쌓여요. 직접 고칠 필요는 없어요(지우면 체크가 풀려요).

## 알아두면 좋은 것
- 사이트 ⚙ **시트 점검**에서 잘못 적혀 못 읽은 칸(예: 날짜 오타)을 알려줘요.
- `Code.gs`가 새 버전이 나오면 아래 방법으로 바꿔요.

## 연결 코드 새 버전으로 바꾸기
사이트에 새 기능(예: 지우기)이 생기면 시트 쪽 코드도 바꿔야 할 때가 있어요. **주소(URL)는 그대로라 사이트·폰은 다시 연결할 필요 없어요.**

1. 시트 → **확장 프로그램 → Apps Script**.
2. 가운데 코드를 **Ctrl + A → Delete**로 다 지우고, [새 코드](https://raw.githubusercontent.com/jun2peter/day/main/apps-script/Code.gs)를 **Ctrl + A → Ctrl + C** 해서 붙여넣기 → **Ctrl + S** 저장.
   (코드 맨 위에 `버전 2`가 보이면 새 코드예요. 안 보이면 몇 분 뒤 새로고침.)
3. 오른쪽 위 **배포 → 배포 관리**.
4. 연필(✏️ 수정) → **버전** 칸에서 **새 버전** → **배포** → 완료.
   ⚠️ "새 배포"를 누르면 주소가 바뀌어서 다시 연결해야 해요. 꼭 **배포 관리**로 하세요.
5. 사이트 새로고침.
- 할 일 이름을 바꾸면 예전 체크 기록과 연결이 끊겨요(기록은 날짜+이름으로 찾아요).
